# Related work and theoretical context

This repository is an original implementation of a small, transparent rule baseline. It does not reproduce a published constructive-alignment instrument and does not claim that verb matching can measure alignment by itself.

## Constructive alignment

Constructive alignment links intended learning outcomes with teaching and learning activities and assessment tasks. A useful practical overview is Advance HE's curriculum-review material:

- Advance HE, Curriculum Reviews: https://advance-he.ac.uk/what-we-do/consultancy/curriculum-reviews/

The broader framework is associated with John Biggs and later editions of *Teaching for Quality Learning at University* by Biggs, Tang, and Kennedy.

## Bloom-style cognitive-process categories

The baseline uses the revised six-level ordering:

1. remember
2. understand
3. apply
4. analyze
5. evaluate
6. create

A concise overview of the revised terminology and definitions is available through Vanderbilt University's Center for Teaching:

- https://cft.vanderbilt.edu/wp-content/uploads/sites/59/BloomsTaxonomy-mary-forehand.pdf

Action-verb lists are useful prompts, but they are not a substitute for reading the full task in disciplinary context.

## Relationship to this repository

The present implementation uses these ideas only as transparent review signals:

- explicit action-verb evidence
- ordinal differences between detected cognitive levels
- lexical overlap as a deliberately simple text baseline
- human-readable flags for cases that may deserve closer review

A future study should compare these rules with expert judgments and semantic text models, paying particular attention to disagreement cases.
